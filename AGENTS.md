# Project Instructions

This is an Angular project.

Before modifying Angular code, follow the guidelines in:

./best-practices.md

Use the Angular best practices described in that file when:
- Creating components
- Using Signals
- Working with RxJS
- Managing state
- Creating services
- Handling dependency injection
- Writing templates
- Structuring the application

Do not ignore these guidelines unless explicitly instructed by the user.

## Living documentation

`PROJECT_OVERVIEW.md` is the living documentation for this project. It covers
the repo layout, the tech stack and the purpose of each technology, the
database schema, backend modules/endpoints, frontend structure, and a change log.

**Every time you make a change** (new feature, model, endpoint, component,
dependency, script, or architectural decision), update `PROJECT_OVERVIEW.md`
in the same change: adjust the relevant section and add an entry to the
change log. Never let the file drift from the actual code.
